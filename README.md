# Portfolio

A personal portfolio built with Next.js, React, Tailwind CSS, and Framer Motion.

## Project setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open `http://localhost:3000` to view the app locally.

## Build

```bash
npm run build
```

## Deployment

This project is ready to deploy to Vercel, which provides a free Next.js hosting workflow.

### Deploy on Vercel

1. Push the repository to GitHub.
2. Go to https://vercel.com and sign in.
3. Import the repository.
4. Vercel will detect Next.js and configure the deployment automatically.
5. After deployment, you will get a public URL where the site is live.

### Alternative deployment options

- Netlify
- Cloudflare Pages
- AWS Amplify

## Notes

- The project uses TypeScript support and Tailwind CSS.
- If you make changes, run `npm run build` to verify the app compiles successfully.
